# Form submissions → Google Sheets

All three website forms (Delegate Registration, Sponsorship Enquiry, Project Interest) post to a
Google Apps Script attached to one Google Sheet. Each form gets its own tab, and emails go out automatically.

| Form | Sheet tab | Email to visitor | Email to team |
|---|---|---|---|
| Delegate registration | `Registrations` | Confirmation with QR pass + calendar invite | Yes |
| Sponsorship enquiry | `Sponsor Enquiries` | Acknowledgement with reference no. | Yes (reply goes to sponsor) |
| Project interest | `Project Interest` | Acknowledgement with reference no. | Yes (+ PI, if configured) |

Built in: duplicate-email check, seat cap, spam honeypot, formula-injection protection, and a lock so
simultaneous submissions can't collide.

## One-time setup (≈15 minutes)

Use the Google account that should **own the data and send the emails** (ideally the Corporate Relations / institute account).

1. **Create the sheet** – go to <https://sheets.new>, name it `CSR Conclave 2026 – Submissions`.
2. **Add the script** – in the sheet: **Extensions → Apps Script**. Delete everything in `Code.gs`,
   paste the contents of [`google-apps-script/Code.gs`](../google-apps-script/Code.gs), click **Save**.
3. **Edit `CONFIG`** at the top of the script:
   - `TEAM_EMAIL` – inbox(es) that get a copy of every submission
   - `REPLY_TO` – where delegate/sponsor replies should go
   - `CAPACITY` – maximum delegates (registration closes automatically)
   - `WEBSITE_URL` – the live site address
   - `PROJECT_PI_EMAILS` – optional, e.g. `'prj-01': 'pi@iitism.ac.in'`
4. **Authorise** – choose `setup` in the function dropdown → **Run** → **Review permissions** → pick the account →
   *Advanced → Go to project (unsafe)* → **Allow**. (Google shows this for any self-written script.)
   The three tabs appear in the sheet.
5. **Deploy** – **Deploy → New deployment** → gear icon → **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   → **Deploy** → copy the **Web app URL** (ends in `/exec`).
6. **Connect the website** – either
   - paste the URL into `src/config.ts` (`const PASTED_URL = 'https://script.google.com/…/exec';`), commit and push, **or**
   - on Vercel/Netlify add an environment variable `VITE_FORMS_ENDPOINT` = the URL and redeploy.
7. **Test** – open the URL in a browser: you should see `{"ok":true,"seatsLeft":500}`.
   Then submit each form on the site once and check the sheet + inboxes. Delete the test rows afterwards.

## Changing the script later

After editing `Code.gs`: **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**.
The URL stays the same, so the website needs no change.

## Day-to-day

- **Export**: File → Download → CSV (per tab).
- **Share with the team**: Share the sheet (Viewer/Editor). Don't share the script editor more widely than needed.
- **Status columns** (`Status`, `Checked in`) are free for the team to fill in.
- **Email quota**: a Gmail account can send ~100 emails/day, a Google Workspace (institute) account ~1,500/day.
  Each registration uses 2 (delegate + team). For 300–500 delegates use the institute Workspace account,
  or remove `TEAM_EMAIL` notifications and rely on the sheet.

## Notes

- The QR image in the confirmation email is generated by quickchart.io from the pass details.
- Running locally (`npm run dev`) without a URL configured simulates success so you can work on the UI;
  a production build without a URL shows "Online submissions are not open yet" instead of silently losing data.
